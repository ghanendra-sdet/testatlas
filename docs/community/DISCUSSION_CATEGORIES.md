# GitHub Discussions Structure

Recommended categories if/when GitHub Discussions is enabled on this repository. Discussions are for open-ended conversation; issues remain for anything actionable (a bug, a correction, a proposal) — see `SUPPORT.md` for that split.

## Categories

**📢 Announcements** (maintainer-only posting)
Release announcements, roadmap updates, major decisions. Read-only for most participants, commentable.

**💡 Ideas**
Early-stage suggestions not yet ready to be a formal Learning Path Proposal issue — "what if TestAtlas covered X" or "would a Y format work better here." A good idea that gains real support here graduates into an issue, per `AUTHOR_GUIDE.md`'s two-stage process (pitch first, then architecture proposal).

**🙋 Q&A**
General questions about using TestAtlas, navigating a path, or understanding a concept — the Discussions equivalent of the Question issue template, for anything conversational rather than needing a tracked resolution.

**🎓 Show and Tell**
Contributors and learners sharing how they used TestAtlas — a study plan, a project they built practicing a technique, an interview they prepared for using it. Purely optional, no obligation to post.

**🛠️ Contributor Chat**
Coordination among people actively contributing — claiming a Good First Issue, asking for early feedback on an in-progress draft, discussing a Learning Path Proposal before it's formalized.

**📚 Curriculum Feedback**
Specific to "I read module X, here's what worked or didn't" — distinct from Content Correction (which is for factual errors) and closer to "this explanation could be clearer," useful signal for future editorial passes even when it doesn't rise to a filed correction.

## What doesn't go here

Bug reports, content corrections, and formal proposals stay as issues — they need a tracked status (open/closed, assigned, labeled) that Discussions doesn't provide. See `SUPPORT.md` for the full routing.

## Moderation

Follows `CODE_OF_CONDUCT.md` and `GOVERNANCE.md`'s conflict-resolution process, same as issues and PRs — Discussions is a TestAtlas space like any other.
