# TestAtlas v1.0.0 — Public Launch

**The Open Software Testing Knowledge Base is live.**

## Highlights

Four complete learning paths. 79 modules. Three of them independently audited and certified as Reference Curricula. A full contributor platform built from real, evidenced experience rather than speculation. This is TestAtlas's first stable, public release.

## What's Included

**Learning Paths**
- **Foundations of Software Testing** (17 modules) — the mindset and vocabulary every other path builds on
- **Manual Testing** (23 modules, certified) — test design technique, artifacts, exploratory testing, reporting, and a real-world capstone
- **API Testing** (21 modules, certified) — HTTP/REST literacy through security, performance, and integration resilience
- **Test Automation** (18 modules, certified) — automation principles, frameworks, reliability, and shipping automation as a real engineering discipline

**Contributor Platform** — `AUTHOR_GUIDE.md`, five task-specific checklists, nine reusable templates, and documented repository standards, so anyone can extend TestAtlas without reverse-engineering conventions from 79 modules.

**Governance** — a stable constitution, decision-making process, and an evidence-based standard for when a curriculum pattern earns formalization (never on first appearance — only after it recurs).

**Community Health** — Code of Conduct, security reporting, contribution templates, and clear routing for questions, bugs, and content corrections.

## Major Milestones

- Three learning paths built and independently certified against the same architecture, each auditing cleaner than the last as lessons compounded forward
- A capstone narrative spanning three paths — the same AtlasBank compliance defect independently rediscovered at the manual, API, and automated-test layers
- A full Platform Consistency Sprint and per-path Certification Sprints, catching and fixing real issues (a path-wide missing-content gap, cross-path duplicate page titles, stale planning documents) before they reached a public audience

## Known Limitations

Honest, not hidden: no public URL existed during development, so Lighthouse/Axe scores, Core Web Vitals, and real assistive-technology testing remain unverified pending deployment. Content-quality validation (heading checks, duplicate-metadata detection) is currently manual/audit-driven — full implementation-ready specs exist, scripts don't yet. See `RELEASE_READINESS.md` for the complete, current list.

## What's Next (v1.1)

Database Testing, Performance Testing, Security Testing, AI for QA, Interview Academy, and Project Simulations — each proposed against the certified Reference Curriculum architecture before a single module is written, the same way every path in this release was built.
