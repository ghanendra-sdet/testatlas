# Foundations v1.0

**Release Date**: 2026-08-03
**Version**: v0.4.0 — Foundations Learning Path Complete

## Highlights

- **17 Learning Outcomes** — one per module, from "explain why testing matters" to "recognize and correct common QA misconceptions"
- **6 Sections** — Introduction → Software Development Context → Testing Fundamentals → Quality Mindset → Defect Management → Professional QA
- **50 Interview Questions** — each with "what to look for" guidance, not just the question
- **67 Glossary Terms** — defined once per module, plus a consolidated cross-referenced reference page
- **65 Common Mistakes** documented, and **68 Best Practices** to counter them
- **15 Full Worked Examples** — real, detailed project walkthroughs, one per module where the module teaches a new technique
- **31 Real-World Opening Scenarios** — the paired "team that gets it wrong / team that gets it right" comparisons that open most modules

## Key Features

- Practical learning — every module built around real decisions, not just definitions
- Real-world scenarios — fintech, healthcare, e-commerce, logistics, and insurance examples throughout, not toy problems
- Interview-ready — 50 questions across the path, each with guidance on what a strong answer actually demonstrates
- Fully cross-referenced glossary — 67 terms, each traceable back to the module that teaches it in depth
- Progressive curriculum — six sections that build in one continuous sequence, each module's Prerequisites block naming exactly what it assumes and unlocks

## What's New

This release completes Foundations, TestAtlas's gateway learning path, in five batches:

- **Modules 1–2** — What testing actually is, and how the QA role fits into product delivery
- **Modules 3–5** — Software Testing Principles, the SDLC/STLC and its models, and Agile & Scrum from a QA perspective
- **Modules 6–7** — Verification vs. Validation and Static vs. Dynamic Testing, taught as a deliberate pair
- **Modules 8–10** — Risk-Based Testing, Quality Attributes, and Shift-Left & Shift-Right Testing
- **Modules 11–13** — Defect Life Cycle, Severity vs. Priority, and Test Strategy vs. Test Plan
- **Modules 14–17** — QA Metrics & Measurement, Common QA Terminology, QA Career Roadmap, and the capstone: Testing Myths & Misconceptions

The path was built, then deliberately restructured mid-way through: a curriculum review reordered several modules and added two identified gaps (Software Testing Principles, Agile & Scrum Basics) before the remaining modules were written — full reasoning documented in `docs/architecture/LEARNING_PATHS.md`.

A learner completing all 17 modules can explain testing's purpose and principles, navigate the SDLC/STLC across different delivery models, distinguish verification from validation and static from dynamic testing, prioritize by risk, manage a defect through its full life cycle with correct severity/priority triage, tell a test strategy from a test plan, read QA metrics skeptically, and describe their own QA career direction — closing by recognizing and correcting seven of the field's most common misconceptions.

*(35,852 words total, for reference — but the numbers above are what actually tell you what's here.)*
